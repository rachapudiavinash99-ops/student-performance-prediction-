# Student Performance Prediction

## Installation
Ensure you have Node.js and Python installed.
Run `npm install` in the frontend directory.
Run `pip install -r requirements.txt` in the backend directory.

## Build
Run `npm run build` in the frontend directory to build the production assets.

## Run
To run the backend: `python main.py` or use docker-compose up.
To run the frontend: `npm run dev`

## Dependencies
- React, TailwindCSS, Vite
- Python, FastAPI, scikit-learn

## Usage
Navigate to http://localhost:5173 to access the dashboard.
